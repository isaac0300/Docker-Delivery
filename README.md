# Docker Delivery

Atividade prática realizada na disciplina de **Segurança e Hospedagem**, como continuação dos projetos anteriores desenvolvidos com Docker.

## Objetivo

Aplicar conceitos de Docker na configuração e execução de uma aplicação composta por **Frontend, Backend e MySQL**, utilizando containers, redes, volumes e Docker Compose.

## Sobre a atividade

O projeto consiste em uma aplicação de delivery composta por **Frontend, Backend e MySQL**, executados em containers separados.

O código da aplicação foi fornecido previamente pelo professor. Nesta atividade, o foco foi aplicar os conhecimentos dos projetos anteriores para configurar a infraestrutura Docker da nova aplicação.

Foram desenvolvidos:

* Dockerfile do Frontend;
* Dockerfile do Backend;
* `docker-compose.yml`.

Também foram configurados novos nomes para os containers, volume, rede e portas utilizadas pela aplicação.

## Tecnologias utilizadas

* Docker
* Docker Compose
* Nginx
* Node.js
* Express
* MySQL
* HTML
* CSS
* JavaScript

## Conceitos estudados

* Criação e configuração de Dockerfiles;
* Utilização do Docker Compose;
* Configuração de containers;
* Criação e utilização de redes Docker;
* Criação e utilização de volumes;
* Configuração de portas;
* Comunicação entre serviços de uma aplicação.

## Contexto acadêmico

Projeto desenvolvido como atividade prática da disciplina de **Segurança e Hospedagem**, utilizando uma aplicação fornecida pelo professor para colocar em prática conceitos de containerização e infraestrutura com Docker.
